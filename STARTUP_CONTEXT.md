# Startup Context
_Last updated: 2025-01-20_

## What we're building
An AI-powered voice-to-text keyboard with automatic text beautification targeting Polish, Ukrainian, Russian, and Belarusian language speakers in Poland. The product differentiates from Grammarly through voice-first input and multi-language support for emigrant communities. Core features: voice-to-text conversion with AI enhancement layer that improves grammar, style, and clarity.

Domain: plyn.io

## Current Status
**Pre-launch validation phase**

- Moving to lean validation approach with fake door landing page before building full product
- Timeline: 2-3 weeks to landing page launch
- Primary goal: Collect emails and test demand in Polish market
- Market opportunity identified: Grammarly only added Polish support in March 2026, no active Polish marketing from competitors
- Key differentiator for virality: Belarusian language support (no mobile keyboards currently support it)

## Key Decisions Made
1. **Product pivot**: From general voice-to-text keyboard to focused AI beautification layer for specific language communities
2. **Target market**: Polish, Ukrainian, Russian, and Belarusian language speakers in Poland (emigrant focus)
3. **Validation approach**: Launch fake door landing page at plyn.io to test demand before building
4. **Competitive positioning**: Position as "better Grammarly" competitor, differentiated by voice-first + multi-language
5. **Go-to-market hook**: Belarusian language support as viral differentiator
6. **Tech stack**: Gemini 2.5 Flash for Belarusian language support
7. **Brand identity**: Green color scheme from holas.ai for beta
8. **Development strategy**: Start with simple beautify feature added to existing voice-to-text, then beta test
9. **Launch timeline**: Compressed to 2-3 weeks to move before competitors enter space
10. **Company approach**: AI-first startup with shared knowledge base and agent in chat to track everything
